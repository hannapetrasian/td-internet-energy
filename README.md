# T&D Internet Energy

Онлайн-игра на 25–30 минут для знакомства команды T&D с новым сотрудником. Статика без сборщика, данные в Firebase Realtime Database.

- Ведущий: `/?host` — создает комнату, показывает экран в демонстрации, ведет игру кнопкой «Дальше».
- Участник: `/?room=XXXX` — выбирает кота, вводит имя, играет с телефона.
- Галерея: `/?room=XXXX&gallery` — карточки «Инструкция по работе со мной», живут после игры.

**Локально:** `python3 -m http.server 8080` из корня и открыть `http://localhost:8080/?host`. С `file://` не работает: ESM-импорты.

**Без сети (для просмотра экранов):** `?host&demo`, `?room=TEST&demo`, `?room=TEST&gallery&demo`. Стрелки ← → листают фазы; `&phase=whois_reveal&step=3` открывает нужную фазу сразу.

**Деплой:** пуш в `main`, GitHub Pages раздает корень репозитория. Firebase: конфиг в `config.js` (шаблон `config.example.js`), правила базы в `firebase.rules.json`.
